No code, ever

Every string is one line that reads Key = words. You replace the words; the key you leave alone.

A piece at a time

The whole file is 222 short words and phrases - buttons, menus, notifications. Send whatever you manage.

The phone follows itself

Once a language is in, the app switches to it when the phone is set to that language. There is no setting to hunt for.

Mistakes are caught

The tool refuses a broken line or a lost {0} and says exactly which line to fix. Nothing wrong can reach the phone.

Five steps, one browser

No software to install and no account to make beyond GitHub itself.

STEP 1

Copy the template

Open MODELLO.txt on GitHub, press Raw, select everything and copy. That is your file to fill in.

STEP 2

Type your language over the English

A notes app is fine. Keep the part before the equal sign untouched and write the translation after it.

STEP 3

Name the file after your language

fr.txt, es.txt, pt.txt... Not sure which letters? Say the language name when you send it and we pick the code.

STEP 4

Send it on GitHub

Add file → Propose changes → Create pull request. Or open an issue and paste your lines in it - both reach us.

STEP 5

A maintainer runs one command

Your file turns into the app's resource for that language, and the table on this page grows a row.

IF YOU PREFER

Paste it into an issue

The repository has an issue form called "Translation". Fill it, paste your lines, send. Files never involved.

Things people ask

What is {0} doing in some lines?
It is a slot the app fills in later: {0} unread messages becomes 5 unread messages. Keep every {0} and {1} exactly where the original has them - the words around them are yours.
And if I make a mistake?
Nothing bad can happen. The tool refuses a file whose lines are broken or whose slots went missing, and it names the exact line to fix. The worst case is a friendly comment on your pull request.
Do the ALL-CAPS words get translated too?
Yes - they are menu and button labels. If your language writes things naturally in lower case, write it that way.
How do I see the app in my language later?
The app follows the phone. Set the phone to your language and the app is in it - no option to turn on, nothing to download separately.
Can I help with something that is not translating?
Yes. The README lists what the project needs: maintainers, reviews, documentation - and the app is unofficial, so a careful reader is worth gold.
