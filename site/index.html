A note from the person who writes the code

I built this app because I wanted WhatsApp on an old Lumia, and the official client is gone. It is a strange kind of project: the protocol is not documented, every version of the app teaches you something, and the reward is seeing a message arrive on a phone nobody supports anymore.

The one thing I cannot do alone is language. I read English and Italian; everything else would be me guessing with a dictionary, and a menu translated by a machine feels like a menu written by a machine. So the translations are the first part of this project I want to hand over to other people. Here is what I can promise about it:

  • No code, ever. Every string is one line that reads Key = words. You replace the words; the key you leave alone. If you can write in a text file, you can do this.
  • A piece at a time is fine. The whole file is 222 short words and phrases - buttons, menus, notifications. Ten lines today and two hundred next month count the same to me.
  • The phone follows itself. When a language lands, the app switches to it as soon as the phone is set to that language. There is no option to hunt for, nothing to download.
  • Nothing broken can reach the phone. The tool refuses a file with a broken line or a lost {0}, and it tells you exactly which line to look at. The worst outcome of a mistake is a comment from me on your pull request.
Vincenzowho writes the code, slowly and happily

P.S. If the template looks long, translate only the buttons you use every day - Send, Chats, Cancel. That is how every language starts. The rest can wait.

Five steps, one browser

It takes longer to read than to do. No software to install, no account beyond GitHub itself.

1

Copy the template

Open MODELLO.txt on GitHub, press Raw, select everything and copy. That is your file to fill in - it is generated from the app's own strings, so it is exactly the right size.

2

Type your language over the English

A notes app is fine. Leave the part before the equal sign alone and write your words after it. Key = words, that is the whole syntax.

3

Name the file after your language

fr.txt, es.txt, pt.txt... Not sure which letters? Say the language name when you send it and I pick the code.

4

Send it on GitHub

Add file → Propose changes → Create pull request. Three buttons. (Or open an issue and paste your lines in it - that reaches me just the same.)

5

I run one command

Your file becomes the app's real resource for that language, and the table on this page grows a row - automatically, straight from the strings.

If pull requests scare you: the repository has an issue form called "Translation". Fill it, paste your lines, send. You never touch a file and it works just as well.

What this project is not

Better said here than discovered later.

It is not official

WhatsApp did not make this and does not approve of it. Linking it is against their Terms of Service and can get an account banned - that is real, not a formality. Use a test or secondary number.

It is not for your new phone

It runs on Windows Phone 8.1, the 2014 one. If you still carry a Lumia, or you like rescuing old hardware, you are exactly who this is for.

It is not on a schedule

One person, spare evenings. Releases come when they are ready and bugs get fixed when they are found. The whole code is open, so you can always see where things stand.

A translation can lag behind

New strings land in English first, and the app falls back to English for those until your language catches up. Nothing breaks - it just speaks two languages for a while.

Things people ask

What is {0} doing in some lines?
It is a slot the app fills in later: {0} unread messages becomes 5 unread messages. Keep every {0} and {1} exactly where the original has them - the words around them are yours.
And if I make a mistake?
Nothing bad can happen. The tool refuses a file whose lines are broken or whose slots went missing, and it names the exact line to fix. The worst case is a friendly comment on your pull request.
Do the ALL-CAPS words get translated too?
Yes - they are menu and button labels. If your language writes things naturally in lower case, write it that way. The capitals are the app's habit, not a rule of yours.
How do I see the app in my language later?
The app follows the phone. Set the phone to your language and the app is in it - no option to turn on, nothing to download separately.
Is this against WhatsApp's rules?
Yes, plainly. It is an unofficial client and using it can get the account banned. I will not pretend otherwise: put a number you can afford to lose on it.
Can I help with something that is not translating?
Please. The README lists what the project needs: people who review, people who write things down, people who read old logs. A careful reader is worth gold around here.
